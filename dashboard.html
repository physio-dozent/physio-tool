Sichtbarkeit pro Semester

Lege fest, welches Semester welche Lerneinheiten zu sehen bekommt. Schüler:innen wählen ihr Semester nicht selbst: Die App erkennt es am Code (erste Anmeldung) oder am Namen (letzte Einsendung).

Speichern: Änderungen werden lokal vorgehalten. Klicke unten auf „kurse.json herunterladen", lade die Datei ins GitHub-Repo unter einheiten/kurse.json hoch und committe. Erst dann wirken die Änderungen für die Schüler.

Semester-Code: Neue Schüler:innen geben beim ersten Mal Name und Code ein und landen im Semester des Codes. Danach reicht der Name. Ohne Code kann ein Semester keine neuen Schüler:innen aufnehmen, bekannte Namen kommen weiter rein. In kurse.json steht nur ein Prüfwert, nicht der Code selbst. Ein neuer Code gilt nach dem Hochladen für alle weiteren Erstanmeldungen.

Lernpfad: Ist er an, öffnen die Themen eines Semesters nacheinander in der Reihenfolge der Liste unten. Das erste Thema ist offen. Das nächste öffnet je Person, sobald im vorherigen der Quiz-Durchschnitt aller vollständigen Runden mindestens 70 % beträgt und ein Kurzfall mindestens 70 % erreicht hat (bei 3 Fragen 3 von 3). Abgebrochene Runden und das Gemischte Quiz zählen nicht, einmal offen bleibt offen. Die Häkchen bestimmen, welche Themen im Pfad sind. Neue Semester starten mit Lernpfad. Ohne Lernpfad sind alle angehakten Einheiten sofort sichtbar.

Fallback: Solange noch kein Semester angelegt ist (oder die Datei nicht im Repo liegt), bleibt der Schüler-Login bei Freitext und alle Einheiten sind sichtbar — wie bisher.
